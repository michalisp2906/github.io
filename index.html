03 / selected work

UK Fuel Pricing Fairness

GitHub Live demo

A peer-relative pricing model that flags UK fuel stations charging above what local market conditions justify. Built on a DuckDB medallion pipeline with GeoPandas spatial features, a LightGBM model validated with spatial cross-validation, and SHAP for explainability. Deployed as a live Streamlit app.

LightGBM DuckDB GeoPandas SHAP Streamlit

NYC Property Price Prediction

GitHub

An ensemble of ARIMA and XGBoost trained on 8,200 New York listings, reaching an R-squared of 0.742. Combines KNN imputation for missing data with NLP feature engineering from listing text using sentence embeddings, tuned with GridSearchCV.

XGBoost ARIMA NLP GridSearchCV

DVLA Vehicle Registration Trends

GitHub

A time-series look at UK vehicle registration data, using ARIMA forecasting to explore trends in vehicle types and fuel categories over time.

Python Pandas ARIMA
